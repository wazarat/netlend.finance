# Longbow reverse-engineering ledger (what netlend.finance mirrors)

Evidence: REA scenario `ev_76783876296954bedb6e446d7456b7ce2844ff743c588ce7a1746ef7d0de6166` (headless capture of /borrow and /earn, 138 requests, complete), browser reads of every route, docs.longbow.cash pages, public JSON API, Morpho/Robinhood docs.

### A1. Architecture (observed)
- **Settlement:** Morpho Blue on Robinhood mainnet `0x9D53d5E3bd5E8d4Cbfa6DB1ca238AEA02E651010`, AdaptiveCurveIRM `0x2BD3d5965B26B51814AC95127B2b80dD6CcC0fa1`, Morpho ChainlinkOracleV2Factory `0xB7c16F6F8cF531447Bf27Ca7220f981E79C9cdF2`. Markets are immutable (collateral, loan, oracle, IRM, LLTV fixed at creation).
- **Vaults:** Morpho **Vault V2** (ERC-4626), factory `0x0FBad98595b0186dA120E41f77C102beb49f803c`, MorphoMarketV1AdapterV2Factory `0x79370Ed003CE325C088E530d5e8655c99c2993e1`, PublicAllocator `0xCe5c1aFa115fF8b1D6913509bfc79D9AE08CC857`. Three vaults: USDG Core (Chainlink-priced only), USDG Frontier (long-tail), ETH (WETH loan). V1 MetaMorpho vault deprecated. 10 % performance fee. Roles: owner/curator/allocator/sentinel, timelocked caps.
- **Multiply (leverage):** Bundler3 `0x6478e9393d4C5bB4d53ee881d1DE78786A0344a6` + GeneralAdapter1 `0xc5E188541D107e8B79e43478bDE365F1406665D6`; Morpho flash loan → Uniswap swap → supplyCollateral → borrow, atomically; slippage floor is oracle-referenced; ~3.9× on 77 % LLTV, ~2.2× on 62.5 %.
- **Oracles:** Chainlink 24/5 stock feeds via adapter factory; Uniswap v3 long-window TWAP for memecoins (LLTV 38.5 %, small caps); API3 for one asset; ERC-4626 exchange rate for spUSDG (LLTV 91.5 %); "Short ETH" = USDG collateral / WETH loan with inverted feed. LLTV tiers observed: 38.5 / 62.5 / 77 / 86 / 91.5 %.
- **Watchdog:** off-chain job compares oracle vs DEX spot and freshness every 15 min–few hours; on divergence sets vault cap for that market to 0 and reallocates idle liquidity.
- **Liquidation engine:** own bot; venue order Uniswap v4 → v3 → Rialto; caps sized to measured exit depth, re-measured daily. Liquidation bonus ≈12.7 % at 62.5 % LLTV (Morpho LIF).
- **Flash loans:** Morpho `flashLoan(token, assets, data)` + `onMorphoFlashLoan` callback, 0 fee.
- **Staking:** Synthetix-style StakingRewards `0xeba502e1177f5fad9432c2deb273569d8381e01a`, stake $BOW, rewards streamed per second in USDG (lending fee share + 5 % of BOW trading fees). Revenue split: vault 80 % / treasury 15 % / stakers 5 %. Borrow rebates via Merkle distributor `0x23e99d72e24dc538c955b9bade710d2ce3a7fca4`.
- **NFT lending:** escrow contract (audited ChainSecurity/Halborn); two modes: instant loan from protocol liquidity at posted terms, or peer-to-peer signed lender offers (EIP-191). Functions seen: `acceptOffer`, `payBackLoan`, `liquidateOverdueLoan`. No oracle, no auto-liquidation; lender keeps NFT after deadline. Collections: Robinhood Punks (10k), StonkBrokers (4,444, ERC-6551).
- **Fixed-rate (detail in `docs/fixed-term-markets.md`, REA `ev_0ea7861e948f61d16500205cc463c50be7459f663556de93937b04fbf7c6a50f`, 2026-10-14):** Midnight `0x6120765Ba5336150BbdDdD0Cd9108B5bFD369632`, offer mempool `0xcEF685D4796FA80F71a97e803D2c0b6719F1b4E2`, `/api/fixed/offers` returns ABI-encoded publications of signed maker offers; six markets, one maturity (24 Oct 2026), best borrow rates 31–35 % APR nine days out. Morpho Midnight markets ("USDG on Morpho Midnight, each against a single collateral, each with its own maturity"), discovered from market-creation logs, offers read from an "offer mempool". Lender quotes a price for 1 USDG at maturity (0.99 → 1.01 % fixed). At maturity any debt is liquidatable; lending locked until repayments.
- **Credit scores:** registry `0x3692de88571F2709c2130b70f0b055c87364651b`, 0–1000, factors repaymentConsistency 0.35, volume 0.20 (log1p(repaid)/log1p(100k)), tenure 0.15 (180 d), diversity 0.10 (4 markets), streak 0.10 (10), base = Σ/0.9×1000, penalty ×max(0, 1−0.2·liquidations), min 2 completed borrows. Served at `/api/credit-score/{address}` and `/methodology`.
- **Rewards:** Depositors Rush (1 % over 28 d on USDG-days, merkle claim), Season One (merkle, weights supply 40/borrow 40/NFT 20), Builders program (50 % of perf fee, `builderCode` attribution, signature registration), referrals.
- **Governance desk:** shareholder voting via OnRecord (third-party, gasless signatures).
- **Agent surface:** hosted MCP (Streamable HTTP) at mcp.longbow.credit with read tools (list_markets, get_market, get_position, get_vault_stats, plan_multiply, estimate_rebate), build-unsigned-tx tools (supply, borrow, repay, stake, claim_rebate, multiply, deleverage) and NFT tools (list/offer/accept/repay/foreclose). Never signs.

### A2. Frontend/back end (observed via REA)
- **Vite + React + viem** SPA (no Next.js); route chunks `Borrow`, `Earn`, `Fixed`, `MultiplyPanel`, `Nft`, `Portfolio`, `Stake`, `Stats`, `Token`, `VaultDetail`, `VaultV2Cards/Panel`, `RushBonus`, `Reserve`, `ActionModal`, `TxError`, `txGuard`, `useNftActions`.
- **First-party API** (Railway behind Vercel): `GET /api/markets` (array; fields `key,name,symbol,isShort,category{Crypto,Stocks,RWA,Memes,Stables,Short},status,loan,price,lltv,maxLTV,oracleLabel,oracleType{chainlink,api3,twap,vault},irm,marketId,collateralAddress,loanAddress,oracle,borrowAPR,supplyAPR,utilization,cap,allocatedUSDG,totalSupply,totalBorrow,listedAt,enabled,isMemeMarket,pendingCapUSDG,preLiqAvailable`), `GET /api/v2/vaults` (`vaults[]{key,slug,name,symbol,address,adapter,asset,decimals,tier,risk,tvl,idle,allocated,withdrawableNow,apy,performanceFee,markets[]{key,marketId,supplyAPR,cap,lltv,hidden}}`, `totals`), `GET /api/stats` (tvl, utilization, openInterest, bowStaked, depositorCount, recentLiquidations, …), `/api/vault/allocation`, `/api/rush`, `/api/logo/{addr}`, `/api/borrow-plan`, `POST /api/multiply-plan`, `POST /api/v2/vaults` (build deposit tx), `/api/nft/loans/record`, `/api/builders/*`, `/api/credit-score/*`.
- Reads chain via Alchemy with public Robinhood nodes as fallback.
